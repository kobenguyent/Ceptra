# Keyboard Shortcuts

Quick reference for every shortcut in **Ceptra**.

## Files, Tabs & Palette

| Shortcut | Action |
| --- | --- |
| `⌘O` | Open CodeceptJS workspace |
| `⌘K` | Open Command Palette |
| `⌘P` | Quick Open file / scenario |
| `⌘N` | New file (template or blank) in current folder |
| `⌘⇧N` | New folder (supports nested paths) |
| `⌘S` | Save active file |
| `⌘⌥S` | Save all modified files |
| `⌘W` | Close active tab |
| `⌘⌥W` | Close other tabs |
| `⌘⇧[` / `⌘⇧]` | Previous / Next open tab |
| `⌘,` | Open Ceptra Settings |

## Test Execution & Parallel Runs

| Shortcut | Action |
| --- | --- |
| `⌘R` | Run all tests (`codeceptjs run`) |
| `⌘⇧R` | Run current test file (auto-resolves owning `-c` config) |
| `⌘⇧D` | Dry run (discover & validate tests) |
| `⌘⇧W` | Run parallel workers (`codeceptjs run-workers`) |
| `⌘⇧M` | Run multiple suites (`codeceptjs run-multiple --all`) |
| `⌘.` | Stop active run or debug session |
| `⌘⇧C` | Choose custom CodeceptJS config file (`-c`) |
| `⌘⇧K` | Focus console command prompt (scripts & shell) |
| `⌘⇧T` | Open workspace folder in System Console |

## Interactive CDP Debugging

| Shortcut | Action |
| --- | --- |
| `⌘⇧B` | Debug current test file with CDP breakpoints |
| `⌃⌘Y` | Continue execution |
| `⌘⇧'` | Step Over |
| `⌘⇧I` | Step Into |
| `⌘⇧O` | Step Out |
| `⌘⌥J` | Toggle Debug & Breakpoints Inspector |

## Editor, Navigation, Folding & Zoom

| Shortcut | Action |
| --- | --- |
| `⌘F` | Find & Replace |
| `Ctrl+Space` | Trigger IntelliSense auto-complete |
| `⌘+Click` / `⌃+Click` / `F12` / `⌃B` | Go to declaration, import target, `I.*` step, or usages |
| `⌃-` / `⌃⇧-` | Navigate Back / Forward across jumped files |
| `⌘⌥[` / `⌘⌥]` | Collapse / Expand code block at caret |
| `⌘⌥⇧[` / `⌘⌥⇧]` | Collapse All / Expand All blocks |
| `⌘+` (`⌘=`) / `⌘−` / `⌘0` | Zoom In / Zoom Out / Reset to 100% (also pinch or `⌘ + scroll`) |

## Code Block Screenshots

| Shortcut | Action |
| --- | --- |
| `⌘⌥P` | Open Code Screenshot Studio (live preview & themes) |
| `⌘⌥⇧P` | Quick Copy 2×/3× Retina PNG of selection or enclosing code block |
| `⌥+Click` camera icon | Quick Copy Code Screenshot from editor tab bar |

## Studio Panels & Inspectors

| Shortcut | Action |
| --- | --- |
| `⌘B` | Toggle Explorer sidebar (left pane) |
| `⌘J` | Toggle Terminal & Logs drawer (bottom) |
| `⌘⌥B` | Toggle Inspector sidebar (right pane) |
| `⌘⌥T` | Toggle Replay Inspector |
| `⌘⌥U` | Toggle CodeceptUI Live |
| `⌘⌥O` | Toggle Flow Outline |
| `⌘⌥J` | Toggle Debug & Breakpoints Inspector |
| `⌘⌥A` | Toggle AI Assistant Inspector |
| `⌘⌥M` | Toggle Mobilewright Device Studio (Live Mirror & Inspector) |
| `⌘⌥I` | Toggle API Client Studio (Postman / Insomnia / OpenAPI / HAR / cURL) |
| `⌘↩` | Send active request (inside API Client Studio) |
